Flexbox & Grid Assignment

Demonstrating modern CSS layout techniques

Flexbox Layout

How it works

This section uses Flexbox. The display: flex property is applied to the container.

  • Settings: justify-content: space-around spaces items evenly.
  • Responsive: When the screen size gets too small, flex-wrap: wrap pushes items to the next line.
  • Features: Perfect for 1-dimensional layouts (rows OR columns).

CSS Grid Layout

How it works

This section uses CSS Grid. The main page container uses display: grid.

  • Settings: grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)) creates a responsive column system.
  • Responsive: Without media queries, the grid automatically adjusts the number of columns based on screen width.
  • Features: Best for 2-dimensional layouts (rows AND columns).
